# v0.1.0-preview.1 — 可恢复测试基线

这是当前已实际测试版本的恢复点，保留诊断功能，作为后续 UI 修复前的基线。

已具备 SteamVR 双眼输出、3DoF 跟头、F2 无限时开关、仅左右方向的 F6 回正、固定前方 UI，以及文字和头像列表的裁切修正。用户已体验更换车辆、LEGO 谷地和比赛，近期对照未发现新异常。

**已知问题**：世界地图内容以及少量按键提示背景（例如 Enter）转头时仍会裁切；本版本没有宣称修复这两项。

适配 Steam FH4 1.478.564.0 / build 12772551。完整安装、运行时分辨率生成、恢复与构建步骤见仓库 README 和运行包 README。

下载 Windows x64 ZIP，并使用同名 .sha256 附件核对；包内另附逐文件 SHA256SUMS.txt。关闭游戏后再复制或恢复文件；已有 dxgi.dll 时先备份。
