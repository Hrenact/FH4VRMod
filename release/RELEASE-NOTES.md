# v0.1.0-beta.1 — 相机周期驱动双眼渲染

首个 beta 预发布版本。左右眼按实际相机周期推进，并追踪渲染端收到的相机来源；同一对双眼保留同一份姿态，减少原先依赖固定帧延迟所造成的停顿和左右跳动。

## 下载与安装

下载 **FH4VRMod-v0.1.0-beta.1-win-x64.zip**（不是 Source code）。关闭 FH4，备份已有模组文件，将 ZIP 解压到 `ForzaHorizon4.exe` 所在目录。

连接头显并启动 SteamVR，双击 `Prepare-VRResolution.cmd`；再启动游戏，选择窗口模式和脚本生成的分辨率，关闭动态模糊。进座舱、朝前按 **F2** 开启，**F6** 仅回正左右方向；F2 再按即关闭，无限时。切回桌面不再自动关闭 VR。

完整的新手步骤见 [README 安装/使用方法省流版](https://github.com/Hrenact/FH4VRMod/tree/v0.1.0-beta.1#安装使用方法省流版)。已有其它模组的 dxgi.dll 时不要直接覆盖；当前没有代理链加载支持。

## 本版验证

- 座舱、暂停菜单、跟头及约 13 分钟高速驾驶通过实际体验，立体感正常，用户反馈高速行驶顺滑。
- 完整驾驶会话提交 66,985 对画面。前约 8 分 25 秒的详细记录平均 86.5 对/秒，双眼对序号连续；两次超过 33 ms 的间隔出现在启动初期。后半段详细记录达到缓冲区上限，不纳入逐帧统计。以上为 CPU 提交统计，不等于头显实际显示帧率。
- 并发来源追踪、姿态保留、GPU 双眼配对与像素、呈现和缩放测试通过。

仅验证 Steam FH4 1.478.564.0 / build 12772551，以及 RTX 4070 + PICO 4 Pro + PICO Connect 无线串流。其它设备尚未验证。

## 已知限制与回退

仍保留极少量偶发跳动、Enter 键盘图标背景裁切、交替渲染时序差异；仅支持旋转跟踪，不支持 6DoF 头部平移。本版保留本地诊断日志和 F2 关闭时保存的时序 CSV，长时间使用会增加磁盘占用。旧 preview Release 保持可下载。

发布 DLL 与实测文件完全一致。包内含 manifest.json 和 SHA256SUMS.txt，另附 ZIP 的 .sha256 校验文件；不包含个人配置、截图、游戏文件或内存样本。
